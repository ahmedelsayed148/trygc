Build a Campaign Management System with Bulk Upload

## Project Overview
Create a comprehensive campaign management dashboard for an operational team using React, TypeScript, Tailwind CSS v4, and Supabase backend. The system manages the complete lifecycle of marketing campaigns across multiple markets (Egypt, KSA, UAE, Kuwait, Qatar, Bahrain, Oman).

## Tech Stack Requirements
- **Frontend**: React 18.3+ with TypeScript
- **Styling**: Tailwind CSS v4 (using inline classes, no config file)
- **Routing**: React Router v7 (use 'react-router' package, NOT 'react-router-dom')
- **Animation**: Motion (from 'motion' package) - import as `import { motion } from 'motion/react'`
- **Icons**: lucide-react
- **Toast Notifications**: sonner
- **Excel/CSV Processing**: xlsx package
- **Charts**: recharts (if needed for analytics)
- **Backend**: Supabase Edge Functions with KV store

## Design System
- **Color Palette**: Strict black & white monochrome with full dark mode support
  - Light mode: white backgrounds, zinc-50/100 for surfaces, zinc-900 for primary actions
  - Dark mode: black/zinc-950 backgrounds, zinc-800/900 for surfaces, zinc-100 for primary actions
- **Typography**: Bold and black font weights throughout (font-bold, font-black)
- **Borders**: Rounded-2xl and rounded-3xl for major containers, rounded-xl for buttons
- **Spacing**: Generous padding (p-6, p-7) with consistent gap-3, gap-4
- **Shadows**: Subtle shadows (shadow-sm, shadow-lg) for depth

5. Excel/CSV Template Generation
Use xlsx library to generate downloadable template:

import * as XLSX from 'xlsx';

function downloadTemplate() {
  const ws = XLSX.utils.aoa_to_sheet([
    ['Campaign Name', 'Client', 'Market', 'Budget (EGP)', 'Start Date', 'End Date', 'Phase', 'Notes'],
    ['Ramadan 2025 - Brand X', 'Brand X', 'EGY', 150000, '2025-03-01', '2025-04-15', 'Planning', 'Focus on stories'],
    ['KSA Launch Q2', 'Brand Y', 'KSA', 80000, '2025-04-01', '2025-05-30', 'Briefing', ''],
  ]);
  const wb = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(wb, ws, 'Campaigns');
  XLSX.writeFile(wb, 'campaigns_template.xlsx');
}
